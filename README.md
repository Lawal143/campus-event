
# UniVibe 🎉

**There's More to Campus Than Lectures.**

UniVibe is a campus event discovery platform designed to help students discover events and activities happening around their university. From technology workshops to MSSN activities and sporting competitions, UniVibe makes it easier for students to stay informed and involved in campus life.

## About the Project

University life goes beyond lectures, assignments and examinations. There are events, opportunities and activities that allow students to learn new things, explore their interests and connect with others.

UniVibe brings these experiences together in one place, helping students find events they might otherwise miss.

## Features

- **Homepage:** A welcoming landing page featuring trending events, upcoming events and event categories.
- **Explore Events:** Browse available campus events.
- **Search:** Find events by their titles.
- **Category Filters:** Filter events by Tech, MSSN Activities and Sports.
- **Date Sorting:** Arrange events by upcoming or latest dates.
- **Event Preview:** View a quick preview of an event before opening its full details.
- **About Page:** Learn more about UniVibe and its purpose.
- **My Events:** A dedicated space for students to keep track of saved events. Saved-event functionality is still being developed.

## Event Categories

UniVibe currently focuses on three categories:

1. **Tech:** Technology workshops, hackathons, meetups and other tech-related activities.
2. **MSSN Activities:** Islamic programmes, gatherings and activities organised within the Muslim student community.
3. **Sports:** Sporting competitions, tournaments and other recreational activities.

## Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Navigate into the project folder

```bash
cd campus_event
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit:

```text
http://localhost:3000
```
